方案概述

在现有视频平台与城市运管服平台上，为「重点道路视频事件智能识别与工单联动」匹配双视角方案：城运中心视角 25 Agent 覆盖质检→识别→证据→去重→指派→预警及隐私旁路（7/7）；承办单位视角 12 Agent 覆盖接单、核查、督办与行政认定（4/5，违规行为整治待匹配）。合计 33 Agent · 35 Skill，部署政务云授权环境，行政认定仍由有权限人员完成。

09

范围与边界

本方案的范围

  • 双视角方案编排与 33 个 Agent 联调
  • 与现有视频平台、工单、热线的数据对接
  • 五类事件识别、去重、派单与督办规则配置
  • 试点道路试运行调优与问题处理
  • 等保与人脸/车牌脱敏策略落地支持

不在本方案内

  • 摄像头硬件采购与道路补点施工
  • 行政认定与执法决定（须人工终审）
  • 违规行为整治现场处置人力（待匹配 Agent）
  • 超出试点范围的全市全量接入
  • 把系统性能等同于部门处置时限

方案成立的前提

  • 视频平台可提供重点道路试点流与点位台账
  • 工单系统开放接收接口与事件分类规则
  • 政务云授权环境与等保定级已明确
  • 职责清单与承办单位目录可获取
